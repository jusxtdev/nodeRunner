## Node-Runner

- A script that prompts user for
  - program to run
  - the number of nodes to run that program
- Use case example
  - running 3 instances of a server program
- each instance of the program will have its own output log
  - if there are 3 nodes printing something to os.Stdout
  - there will be 3 files - `node1.log` `node2.log`
  - i.e. each routine will manage getting the output from the program and writing to its logfile

#### Package and Directory Purpose

- `cmd/node-runner`: application entry point and dependency wiring.
- `internal/cli`: prompts and parsing for user input.
- `internal/node`: node state, lifecycle, peer information, and coordination.
- `internal/process`: launching external commands, capturing output, and detecting process exits.
- `internal/logging`: creating and managing a separate log file for each node.
- `logs`: runtime log output generated by managed nodes.

#### Component Responsibilities

- `main.go`: starts the application, constructs dependencies, connects the packages, handles top-level errors, and controls the application lifetime. It should remain thin and contain no prompt or node-management logic.
- `cli`: prompts for input, parses and validates configuration, calls the node manager, and displays status or errors to the user.
- `node.Manager`: creates and coordinates multiple nodes, starts and stops them, tracks their status, handles restarts, monitors failures, and coordinates shutdown.
- `process`: controls one underlying operating-system process. It builds and starts commands, passes arguments and environment variables, captures output, waits for completion, and sends termination signals.
- `logging`: creates a log file for each node, writes stdout and stderr to the correct file, optionally adds timestamps or node identifiers, and closes log files.

The main flow is:

```text
main
└── cli.Run
    └── node.Manager
        ├── process.Runner for node 1
        │   └── logging.Logger for node 1
        ├── process.Runner for node 2
        │   └── logging.Logger for node 2
        └── process.Runner for node 3
            └── logging.Logger for node 3
```

### Working

Runs `n` instances of a program in their own goroutine

#### Startup

- prompt for destination of the program
- also ask for the command to execute that program
  - Ex. - `go run ./other/main.go`
- ask for number of nodes to run for that program
- create a Node struct for each

```go
type Node struct {
    NodeID int
    Port int        // 8081 to run on localhost:8081
    Peers []int     // array of Port address of other Nodes
}
```

#### Running

- a goroutine for each Node is started
- logging for each node is done in their separate log files
- the client (from the main program) is notified if any of the nodes has crashed or reported an error
